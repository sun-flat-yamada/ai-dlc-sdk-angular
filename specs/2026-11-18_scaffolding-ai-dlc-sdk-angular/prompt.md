# spec.md 作成プロンプト

gemini-4-argon (high)

AI-DLC 用の SDK を作成する。以下の条件でClaudeCodeにScaffoldingさせるための spec.md ファイルを作成せよ。

- GitHub Copilot CLI を用いる。
- 要件をインプットし、UnitTestまでをAIに自律実施させる。
- 既存のコードベースがあり、流用(積極的には変更しない)構造の指定がある。一部は無視したり作り直し、削除してもよい領域もある。
- Angularを採用したGUIアプリケーションである。組込み機器のフロントパネルGUI用アプリケーションで、HTMLやCSSの画面デザイン仕様と、機能を実現するためのREST APIリソースの仕様がある。
- 設計書などは実装後に人間が解釈する軸でリバース生成する。
- 人間が実施した同一要件の開発とQCD結果を比較する。
- 人間が実施したサブシステムテスト (Excelシートのテストケース) を元に、自動実施できるテストを作成して最終品質ゲートとして評価する。
- 品質ゲートをクリアするまでは最大N回(パラメーター指定可能)自律的にループして改善を繰り返す。
